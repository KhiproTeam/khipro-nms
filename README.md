# ⚠️ Repository Archived

This repository is no longer maintained, and the layout file is outdated. Since the last release of this file, Khipro has been upgraded many times. To use the latest Khipro on Windows, users are recommended to use [Khipro Windows Portable](https://github.com/KhiproTeam/khipro-windows-portable/) or [Borno Windows](https://codepotro.com/borno/).

# Instructions

> [!Warning]
The layout file is quite outdated, so please avoid using it. For the full Khipro experience on Windows, please check the alternative options.

To use **Khipro** on the **Nms Kontho** keyboard:

1. Download the **Khipro (Custom).nmsLayout** file.
2. Import the layout into the **Kontho** keyboard.
3. Restart the Kontho keyboard, select the **Khipro (Custom)** layout, and start typing in Bangla.
